## 1. 实验概述

### 1.1 研究背景

多智能体物流调度系统是一种结合大语言模型(LLM)、检索增强生成(RAG)技术和多智能体仿真的智能物流解决方案。系统通过RAG技术获取物流领域知识，利用LLM生成调度指令，并驱动机器人(Robot)、卡车(Truck)、无人机(UAV)三类Agent完成物流配送任务。

### 1.2 实验目的

本实验旨在系统化评估多智能体物流调度系统的性能表现，主要包括：

1. **RAG技术对比**：评估不同RAG策略对系统响应时间和决策质量的影响
2. **调度策略优化**：对比不同调度算法的性能差异
3. **系统鲁棒性**：测试系统对参数扰动的敏感程度
4. **性能基准建立**：为后续优化提供参考基线

### 1.3 实验范围

| 实验类型 | 实验目的 | 样本数量 |
|---------|---------|---------|
| 消融实验 | 评估RAG检索策略 | 18次 |
| 基线实验 | 建立性能基准 | 10次 |
| 对比实验 | 对比调度策略 | 18次 |
| 鲁棒性实验 | 测试参数敏感度 | 46次 |

## 3. 实验指标定义

### 3.1 核心指标

| 指标类别 | 指标名称 | 英文标识 | 说明 | 单位 |
|---------|---------|---------|------|------|
| **RAG指标** | RAG检索时间 | rag_search_time | RAG服务检索相关文档的耗时 | 秒(s) |
| | RAG查询生成时间 | rag_query_generation_time | LLM生成RAG检索关键词的耗时 | 秒(s) |
| **LLM指标** | LLM总推理时间 | llm_total_time | LLM端到端推理总耗时 | 秒(s) |
| | LLM查询生成时间 | llm_query_gen_time | LLM生成检索查询的耗时 | 秒(s) |
| | LLM指令生成时间 | llm_command_gen_time | LLM生成Agent指令的耗时 | 秒(s) |
| **仿真指标** | Robot仿真时间 | robot_simulation_time | 机器人物理仿真运行时间 | 秒(s) |
| | Truck仿真时间 | truck_simulation_time | 卡车物理仿真运行时间 | 秒(s) |
| | UAV仿真时间 | uav_simulation_time | 无人机物理仿真运行时间 | 秒(s) |
| **总体指标** | 总耗时 | total_time | 从用户输入到仿真完成的端到端时间 | 秒(s) |
| | 成功率 | success_rate | Agent任务执行成功率 | 百分比(%) |

### 3.2 派生指标

| 指标名称 | 计算公式 | 说明 |
|---------|---------|------|
| 时间误差率 | `|仿真时间 - 真实时间| / 真实时间` | 仿真与真实配送时间的偏差 |
| 敏感度系数 | `输出变化率 / 输入变化率` | 参数变化对系统性能的影响程度 |
| RAG时间占比 | `RAG检索时间 / 总耗时` | RAG检索在总流程中的时间占比 |

### 3.3 敏感度级别定义

| 敏感度系数绝对值 | 级别 | 说明 |
|-----------------|------|------|
| < 0.1 | 低敏感 | 参数变化对系统影响很小 |
| 0.1 - 0.5 | 中敏感 | 参数变化有一定影响 |
| 0.5 - 1.0 | 高敏感 | 参数变化影响显著 |
| > 1.0 | 极高敏感 | 参数变化影响极大 |

### 4.5 消融实验分析

#### 4.5.1 RAG检索时间对比

```
GraphRAG (34.63s) < Text RAG (52.54s)
```

GraphRAG检索时间比Text RAG减少约**34%**。原因分析：
- GraphRAG利用知识图谱的结构化特性，检索路径更短
- Text RAG需要遍历向量空间进行相似度计算

#### 4.5.2 总耗时对比

```
no_rag (159.85s) < graphrag (230.43s) < text_rag (258.71s)
```

- 启用RAG后总耗时增加约**44%~62%**
- GraphRAG相比Text RAG节省约**11%**的总耗时

#### 4.5.3 成功率分析

| 配置 | Robot成功率 | UAV成功率 |
|------|------------|----------|
| no_rag | 100% | 83.3% |
| text_rag | 100% | 83.3% |
| graphrag | 100% | 83.3% |

三种配置的成功率一致，说明RAG对任务执行成功率影响有限，主要影响响应效率。

### 4.6 消融实验结论

1. **无RAG配置响应最快**，但缺乏领域知识支持，可能导致决策质量下降

2. **GraphRAG优于Text RAG**：
   - 检索时间减少34%
   - 总耗时减少11%
   - 知识结构化程度更高

3. **建议**：对于需要准确领域知识的物流调度场景，推荐使用GraphRAG配置
