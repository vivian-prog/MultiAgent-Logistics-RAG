### 2.1 实验目标

- 基础实验（Baseline）

- 鲁棒性实验（Robustness）
- 对比实验（Comparison）

实验重点关注系统在检索增强、任务生成、三类智能体协同执行以及高层调度策略差异下的综合性能表现。

## 3. 实验指标

本研究的实验指标主要来自 `experiment_details.csv` 中的字段定义，可分为以下四类。

### 3.1 检索与推理指标

- `rag_search_time_s`：RAG 检索耗时
- `rag_query_generation_time_s`：RAG 查询生成耗时
- `llm_total_time_s`：LLM 总思考耗时
- `llm_query_gen_time_s`：LLM 查询生成耗时
- `llm_command_gen_time_s`：LLM 指令生成耗时

这些指标用于衡量系统在“检索增强 + 指令生成”阶段的开销。

### 3.2 智能体仿真指标

- `robot_simulation_time_s`：仓储机器人仿真时间
- `truck_simulation_time_s`：卡车仿真时间
- `uav_simulation_time_s`：无人机仿真时间

这些指标用于表征三类智能体在任务链中的执行成本。

### 3.3 成功性指标

- `robot_success`
- `truck_success`
- `uav_success`
- `record_status`

其中，`record_status` 表示实验记录是否成功生成；三类 `*_success` 用于判断对应智能体任务是否真实执行成功。因此，论文分析中需要区分：

- “实验已执行并记录”
- “三类智能体全部成功完成任务”

### 3.4 总体指标

- `total_time_s`：端到端总耗时

该指标综合反映了从检索、推理到多智能体执行的整体时间开销，是论文实验对比中的核心指标之一。

### 4.3 Ablation 实验结果

消融实验共包含 4 组配置，用于比较不同检索增强策略对系统整体性能的影响。  
其核心配置通常包括：

- 无 RAG
- Text RAG
- Raw Text RAG
- GraphRAG

从实验设计上看，该组实验主要用于回答以下问题：

- 检索增强是否能提升任务规划的稳定性；
- 不同 RAG 形式在推理质量和耗时之间如何权衡；
- GraphRAG 是否在复杂物流任务中具有更好的适配性。

论文写作建议表述：

> 消融实验用于验证检索增强模块对任务规划质量与系统稳定性的贡献。不同配置下的实验结果能够反映纯 LLM、文本级检索以及图结构检索在多智能体物流调度场景中的适用差异。

### 4.4 Robustness 实验结果

鲁棒性实验共包含 23 组记录，主要针对 UAV 与 Robot 的关键参数进行扰动，包括但不限于：

- UAV 耗电速率
- UAV 最大速度
- Robot 耗电速率
- Robot 移动速度

该组实验的目标是评估系统在参数变化条件下的稳定性与敏感度。  
与基础实验相比，鲁棒性实验更强调系统在复杂动态条件下是否仍能完成任务，以及任务完成时间是否出现明显波动。

论文写作建议表述：

> 鲁棒性实验表明，系统能够在一定范围内适应智能体关键参数的变化，但不同参数对系统性能的影响程度存在明显差异。速度与耗电相关参数会直接影响任务完成时间和任务成功率，因此可作为后续调度优化的重要关注因素。

### 4.5 Comparison 实验结果

对比实验共包含 3 组配置，分别对应：

- 基线方案（Baseline）
- 蚁群算法（ACO）
- 遗传算法（GA）

该组实验用于评估传统启发式优化算法在高层调度阶段相较于默认基线方案的效果。  
对比实验的研究意义主要在于：

- 分析高层调度策略对整体系统耗时的影响；
- 比较不同算法在多资源选择问题上的适应性；
- 观察传统优化算法与 LLM 驱动规划之间的结合效果。

论文写作建议表述：

> 对比实验说明，将 ACO 与 GA 等启发式优化算法引入高层调度后，可以从资源选择与调度策略角度为系统提供额外优化空间。这类实验有助于验证“LLM + 传统优化算法”混合框架的有效性。

## 5. 各类型实验结论

### 5.1 Baseline 实验结论

Baseline 实验为系统提供了统一的基准结果，说明在默认配置下，系统能够完成从检索增强、任务生成到多智能体执行的完整闭环，并为后续所有实验提供对照标准。

### 5.2 Ablation 实验结论

消融实验说明，检索增强模块对多智能体物流任务具有重要作用。不同 RAG 配置在推理稳定性、时间开销和任务可执行性方面存在差异，因此检索模块并非可有可无，而是影响系统整体性能的重要组成部分。

### 5.3 Robustness 实验结论

鲁棒性实验表明，系统对智能体参数扰动具有一定适应能力，但不同参数的影响强度并不一致。与速度、能耗相关的参数变化会显著影响任务执行效率，说明系统在真实部署前仍需结合参数敏感性进行优化。

### 5.4 Comparison 实验结论

对比实验说明，不同高层调度算法会对整体系统表现产生直接影响。引入 ACO 和 GA 等启发式优化算法，有助于从资源选择与调度策略层面提升系统性能，为后续构建更高质量的混合调度框架提供了可行方向。
