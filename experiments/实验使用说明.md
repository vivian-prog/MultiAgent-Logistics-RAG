# 实验主程序使用说明

## 概述

`ex_main.py` 是多智能体物流调度系统的实验主程序，支持以下实验类型：
- 基础实验组 - 收集三种 Agent 仿真时间、RAG 操作耗时、LLM 思考耗时
- 消融实验 - RAG vs GraphRAG vs 无 RAG
- 鲁棒性实验 - 修改 Agent 耗电速度等参数
- 对比实验 - 不同算法策略对比

## 输出位置

**默认目录**: `experiments/results/`

输出文件：
| 文件名 | 说明 |
|--------|------|
| `experiment_log_YYYYMMDD_HHMMSS.txt` | 所有控制台输出的日志文件 |
| `baseline_metrics.csv` | 基础实验指标 |
| `ablation_xxx_metrics.csv` | 消融实验指标 |
| `robustness_xxx_metrics.csv` | 鲁棒性实验指标 |
| `comparison_xxx_metrics.csv` | 对比实验指标 |
| `experiment_summary.txt` | 汇总报告 |

## 命令行参数

### 实验类型选择

| 参数 | 说明 |
|------|------|
| `--all` | 运行所有实验 |
| `--baseline` | 运行基础实验组 |
| `--ablation` | 运行消融实验 |
| `--robustness` | 运行鲁棒性实验 |
| `--comparison` | 运行对比实验 |

### 参数配置

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--output` | str | `experiments/results/` | 结果输出目录 |
| `--prompts` | list | DEFAULT_PROMPTS | 自定义测试 prompts |
| `--prompts-file` | str | None | 从 JSON 文件加载 prompts |
| `--repeat` | int | 1 | 每配置重复次数 |
| `--overwrite` | flag | False | 覆盖已有结果文件 |

### 鲁棒性实验专用

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--agents` | list | `["uav", "robot"]` | 鲁棒性实验的 Agent 类型 |

## 使用示例

### 基本用法

```bash
# 默认运行所有实验，输出到 experiments/results/
python ex_main.py

# 仅运行基础实验组
python ex_main.py --baseline

# 仅运行消融实验
python ex_main.py --ablation

# 仅运行鲁棒性实验
python ex_main.py --robustness

# 仅运行对比实验
python ex_main.py --comparison
```

### 指定输出目录

```bash
# 输出到指定目录
python ex_main.py --output ./my_results

# 输出到指定目录并运行基础实验
python ex_main.py --output ./my_results --baseline
```

### 覆盖旧结果

```bash
# 覆盖已有的 CSV 结果文件
python ex_main.py --overwrite

# 指定目录并覆盖
python ex_main.py --output ./my_results --overwrite
```

### 自定义测试数据

```bash
# 使用自定义 prompts
python ex_main.py --prompts "任务1描述" "任务2描述"

# 从 JSON 文件加载 prompts
python ex_main.py --prompts-file prompts.json
```

### 设置重复次数

```bash
# 每个配置重复运行 3 次
python ex_main.py --baseline --repeat 3
```

### 鲁棒性实验参数

```bash
# 测试 UAV 和 Truck 的鲁棒性
python ex_main.py --robustness --agents uav truck

# 测试所有 Agent 类型的鲁棒性
python ex_main.py --robustness --agents uav truck robot
```

## 覆盖行为说明

| 模式 | CSV 文件 | 日志文件 |
|------|----------|----------|
| 不加 `--overwrite` | 追加模式 | 每次运行创建新文件（带时间戳） |
| 加 `--overwrite` | 覆盖模式 | 每次运行创建新文件（带时间戳） |

> **注意**: 日志文件始终带时间戳命名，不会覆盖旧的日志文件，方便追溯历史运行记录。

## 输出指标说明

CSV 文件包含以下字段（单位：秒）：

| 字段名 | 说明 |
|--------|------|
| `rag_enabled` | 是否启用 RAG |
| `rag_type` | RAG 类型 |
| `rag_search_time_s` | RAG 检索耗时 |
| `rag_query_generation_time_s` | RAG 查询生成耗时 |
| `llm_total_time_s` | LLM 总思考耗时 |
| `llm_query_gen_time_s` | LLM 生成 RAG 查询耗时 |
| `llm_command_gen_time_s` | LLM 生成指令耗时 |
| `robot_simulation_time_s` | Robot 仿真时间 |
| `truck_simulation_time_s` | Truck 仿真时间 |
| `uav_simulation_time_s` | UAV 仿真时间 |
| `robot_success` | Robot 是否成功 |
| `truck_success` | Truck 是否成功 |
| `uav_success` | UAV 是否成功 |
| `total_time_s` | 总耗时 |
