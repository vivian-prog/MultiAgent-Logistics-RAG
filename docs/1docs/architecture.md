## 6. 关键配置项

| UnderstandingForBotEventName | Bot任务EventBus Topic | constdef/constants.go |
| UnderstandingForFullEventName | 完整处理EventBus Topic | constdef/constants.go |
| GptHost | GPT API地址 | constdef/constants.go |
| OpenAPIAK | API密钥 | constdef/constants.go |
| StrategyClassifyMode | 分类模式选择 | tcc动态配置 |
| PromptVideoCaption | 视频描述Prompt配置 | tcc动态配置 |
| PromptClassify | 分类Prompt配置 | tcc动态配置 |
